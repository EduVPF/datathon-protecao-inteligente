# Ferramentas da equipe

| O quê | Onde |
|---|---|
| Código | [GitHub (privado)](https://github.com/matfsouza/datathon-bb-seguro-residencial) |
| Tarefas | [GitHub Projects](https://github.com/users/matfsouza/projects/1), vazio até o grupo fechar o plano |
| CSVs, áudios, vídeos, prints | Google Drive (pasta compartilhada) |
| Slides | Google Slides, dentro da pasta do Drive |
| Conversa | Grupo de WhatsApp |
| Cérebro do projeto | Este vault, só no meu computador |

O Trello não é necessário: o GitHub Projects liga cada cartão à issue, à branch e ao commit.

Dados de clientes e arquivos pesados ficam fora do Git por causa da LGPD e do limite de tamanho. Cada um baixa do Drive para a sua pasta `data/raw/`.

Resumos de conversa vão para [[Reuniões]]. Se algo for útil para o grupo todo, eu mando no WhatsApp ou coloco no Drive.
