# Cronograma e papéis

## Papéis sugeridos (5 pessoas)
| Papel | Responsável | Faz o quê |
|---|---|---|
| **Líder / Produto** | | Mantém o foco no problema, decide escopo, cuida do pitch |
| **Dados 1 — Ingestão & EDA** | | Lê os CSVs, junta as bases, dicionário de dados, gráficos |
| **Dados 2 — Motor** | | Regras de perfil, grau de confiança, faixas de cobertura, template |
| **Dev MVP** | | Streamlit: tela do gerente e do cliente (click-to-buy) |
