# Roteiro da apresentação gravada (~5 min)

| Bloco | Tempo (de 5 min) | Conteúdo |
|---|---|---|
| 1. Problema | 0:30 | A entrevista é longa, o cliente não sabe responder ("quanto valem seus eletrônicos?") e desiste |
| 2. Insight dos dados | 1:00 | O que os sinais já dizem: % de imóveis com perfil inferido com alta confiança |
| 3. Solução | 0:45 | Motor: perfil + confiança → 2–3 perguntas → plano + faixas + motivo |
| 4. Demo | 1:30 | Gerente vê proposta e argumento → cliente confirma e contrata no app |
| 5. Impacto | 0:45 | Perguntas economizadas, cobertura adequada, tempo do gerente |
| 6. Próximos passos | 0:30 | Dados externos de risco, piloto com grupo controle, outros canais |
