# Economia comportamental aplicada

Princípios que ajudam a jornada, com o limite ético de cada um. Regra geral: o motor recomenda pela **necessidade**; a forma de mostrar só ajuda a entender.

| Princípio | Como usar | Limite |
|---|---|---|
| **Efeito compromisso** | 3 opções com a do meio destacada. O AFM (regulador holandês) viu a escolha da apólice padrão cair de 71% para 49% quando apareceram opções mais caras ao lado | Destacar só o que o motor recomendou pela necessidade, não o mais lucrativo |
| **Menos esforço** | Proposta pronta, poucas perguntas (pesquisa CEB/Gartner) | Não esconder informação para "facilitar" |
| **Aversão à perda** | "Se um vazamento atingir o vizinho, você paga do seu bolso" | Exemplos reais da casa dele, sem assustar |
| **Excesso de escolha** | No máximo 3 planos e 3 perguntas | |
| **Atrito bom × atrito ruim (sludge)** | Uma checagem antes de contratar é atrito bom; dificultar cancelar é atrito ruim | Desde a Consumer Duty, a FCA cobra que as empresas não explorem vieses do cliente |
| **Padrão (default)** | Pré-preencher o que tem confiança alta | Nunca pré-marcar adicional que o cliente não precisa |
