# Seguro que se atualiza

**Como funciona:** Quando os dados mudam (compra grande, reforma), o sistema sugere ajustar a cobertura para não ficar subsegurado.

**Por que vale:** Resolve o problema de dados desatualizados que a banca citou.

**Esforço:** Próximos passos.
